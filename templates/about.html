About FingerSecure AI

FingerSecure AI is a deep learning based fingerprint liveness detection system designed to identify whether a fingerprint is genuine or a presentation attack before authentication.

AI Powered

Uses a MobileNetV3-Small deep learning model trained on fingerprint presentation attack datasets to distinguish LIVE and SPOOF fingerprints.

Secure Authentication

Detects printed, replayed and artificial fingerprint attacks before granting biometric authentication.

Fast Inference

Optimized for real-time deployment with lightweight architecture and high-speed inference.

Technology Stack


Python • Flask • PyTorch • MobileNetV3 • HTML5 • CSS3 • JavaScript


Project Objective


Enhance biometric security by verifying fingerprint liveness and preventing spoof attacks before authentication.
